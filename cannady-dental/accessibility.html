Accessibility Statement

  • Text alternatives for meaningful images
  • Color contrast that meets or exceeds WCAG 2.1 AA thresholds
  • Keyboard-accessible navigation, including a "skip to main content" link
  • Descriptive labels on all form fields and interactive controls
  • Responsive design that supports zoom up to 200 % and mobile screen readers
  • Automated accessibility testing across every page of the site, with issues fixed as found

Ongoing Efforts

Accessibility is an ongoing effort, not a one-time project. We periodically re-test the site with automated tools (axe-core) and review new content against WCAG 2.1 AA before publishing. Some third-party content we link to (such as our online booking provider) is operated by other companies; we encourage those vendors to maintain accessible experiences and will assist any patient who has difficulty booking online.

Need Assistance or Found a Problem?

If you experience any difficulty accessing part of this website, or if you would like to request information in an alternative format, please contact us. We will make every reasonable effort to assist you promptly — including scheduling appointments by phone.

When reporting an issue, it helps to include the web address of the page and a brief description of the problem. We aim to respond within two business days.
