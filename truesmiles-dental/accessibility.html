TrueSmiles Dental is committed to ensuring digital accessibility for people with disabilities. We are continually improving the user experience for everyone and applying relevant accessibility standards. Accessibility Features We have implemented the following accessibility features on our website: Keyboard navigation — All functionality is accessible via keyboard
  • Skip to content link — Allows keyboard users to skip navigation
  • Descriptive link text — Links clearly describe their destination
  • Color contrast — Text meets WCAG 2.1 contrast requirements
  • Resizable text — Text can be enlarged without loss of functionality
  • Form labels — All form fields have associated labels
  • ARIA landmarks — Proper semantic structure for screen readers
  • Alt text — Images include descriptive alternative text

Standards

We aim to conform to WCAG (Web Content Accessibility Guidelines) 2.1 Level AA standards. These guidelines explain how to make web content more accessible to people with disabilities.

Ongoing Efforts

  • Reviewing our website regularly for accessibility
  • Training staff on accessibility best practices
  • Addressing accessibility issues promptly
  • Seeking feedback from users with disabilities

Physical Accessibility

Our office is physically accessible, with features including:

  • Ground-level entrance with accessible parking
  • Wide doorways and hallways
  • Accessible restrooms
