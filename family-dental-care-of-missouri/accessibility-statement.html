Accessibility

Accessibility Statement

Family Dental Care Missouri wants this website to be usable by everyone, including people using screen readers, keyboard navigation, magnification and other assistive technology.

Our standard

This site is built to the Web Content Accessibility Guidelines (WCAG) 2.1 Level AA as its target: every text and background color pairing on the site is contrast-checked to AA, all interactive elements including the expandable question sections are native HTML controls that work with keyboards and screen readers, images carry descriptive alternative text, pages use a logical heading structure, and the site remains fully readable with styles disabled and without JavaScript.

Ongoing work

Accessibility is maintained, not achieved once: new pages are held to the same checks before publication, and we review the site when standards or tools change.

Tell us if something is not working

If any part of this website is difficult to use with your technology, we genuinely want to know, and we will provide the information you were seeking by phone or another format you prefer while we fix the page.
