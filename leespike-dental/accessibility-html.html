Accessibility Statement

  • Descriptive alt text on informative images
  • Keyboard-operable navigation, menus, and accordions
  • Sufficient color contrast between text and background
  • Correct lang attributes on each page for assistive technology
  • Motion and scroll animations that respect the prefers-reduced-motion setting
  • Responsive layout that adapts to zoom, mobile, and screen-reader use

Ongoing efforts

Accessibility is an ongoing effort. We periodically review our website and welcome feedback from patients using assistive technology.
