Accessibility Features On Our Website

The following is a list of items we have included in our website to improve its accessibility:

  • ✅ Meaningful alt text for all informative images
  • ✅ Sufficient color contrast between foreground and background elements
  • ✅ Full keyboard navigability for menus, buttons, and forms
  • ✅ Proper heading structure ( h1 , h2 , etc.) for logical screen reader flow
  • ✅ Clear and descriptive form labels , with ARIA tags where needed
  • ✅ Resizable text and compatibility with browser zoom features
  • ✅ Accessible and intuitive navigation design
  • ✅ A commitment to providing captioned video content when available
  • ✅ A visible focus indicator for users navigating via keyboard
