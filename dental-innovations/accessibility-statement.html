Accessibility Statement

  • Added descriptive alternative text ("alt text") for meaningful images.
  • Improved text readability with body text set to a minimum of 16px and headings set to a minimum of 24px.
  • Removed unnecessary animations and motion effects to reduce visual distractions and improve user comfort.
  • Organized content using a clear and consistent heading structure.
  • Added the appropriate language attribute to the website to improve screen reader compatibility.
  • Added visible labels and accessible ARIA labels for contact form fields.
  • Improved contact form accessibility with visible keyboard focus indicators and enhanced keyboard navigation.
  • Improved keyboard navigation throughout the website, including the primary navigation and dropdown menus.
  • Added custom ARIA labels to interactive elements, including social media icons and buttons, to provide more descriptive information for screen reader users.
  • Tested pages using the WAVE Web Accessibility Evaluation Tool to identify and resolve accessibility issues.
  • Verified compatibility with screen readers on both macOS and Windows platforms.
  • Ensured the website remains functional and readable when browser zoom is increased up to 200 %.
  • Continue to review and improve website accessibility through ongoing testing and updates.
